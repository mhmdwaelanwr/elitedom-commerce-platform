## 1. Introduction & Purpose
This glossary defines standard business, technical, and operational terms utilized across all documentation and systems for the **Elitedom Store** platform.

---

## 2. Terminology Definitions

| Term | Definition |
| :--- | :--- |
| **API** | Application Programming Interface. |
| **B2B** | Business-to-Business institutional or bulk sales segment. |
| **B2C** | Business-to-Consumer retail sales segment. |
| **COD** | Cash on Delivery payment method. |
| **CRM** | Customer Relationship Management module. |
| **CSAT** | Customer Satisfaction Score metric. |
| **ERP** | Enterprise Resource Planning system (Odoo 17). |
| **KPI** | Key Performance Indicator used to measure business success. |
| **ODM** | Original Design Manufacturer. |
| **OEM** | Original Equipment Manufacturer. |
| **Odoo** | The core enterprise resource planning platform powering Elitedom operations. |
| **RBAC** | Role-Based Access Control security mechanism. |
| **RMA** | Return Merchandise Authorization for warranty and return claims. |
| **SKU** | Stock Keeping Unit code identifying product variants. |
| **SMB** | Small and Medium-sized Business. |
| **UAT** | User Acceptance Testing. |
