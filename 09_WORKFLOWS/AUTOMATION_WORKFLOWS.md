## 1. Overview
This document defines the operational workflows, document lifecycle, and background automation rules for **Elitedom Store** within **Odoo 17 ERP**. It establishes standard operating procedures for fulfillment, supplier management, warranty claims, and zero-cost server maintenance.

---

## 2. Direct Retail Workflow (In-Stock Hardware)
*Applies to hardware inventory stored in local warehouse facilities.*

```text
[Customer Order] ➔ [Reserve Inventory] ➔ [Scan Serial Number] ➔ [Dispatch & SMS] ➔ [Send Invoice]

```
 1. **Order Placement:** The customer places an order online -> Odoo automatically generates a confirmed **Sales Order (SO)**.
 2. **Stock Reservation:** Odoo reserves the specific inventory item immediately to prevent double-selling.
 3. **Picking & Serial Scan:**
   * Warehouse staff opens the **Delivery Order (DO)**.
   * Staff scans the item's unique **Serial Number (S/N)** using a barcode scanner to bind it to the customer ticket.
 4. **Shipping & Notification:** The package is dispatched with **Elitedom** branded packaging. The customer receives an automated SMS update via **Twilio** with tracking details.
 5. **Invoicing:** Odoo generates a PDF **Customer Invoice** and sends it directly to the customer's inbox via **SendGrid**.
## 3. Automated Dropshipping Workflow
*Applies to supplier-owned inventory shipped directly from vendors to customers.*
```text
[Customer Purchases] ➔ [Auto-Generate Purchase Order] ➔ [Vendor Dispatch] ➔ [Customer Delivery]

```
 1. **Route Trigger:** The product is configured with the Dropship Route in Odoo.
 2. **Automated Purchase Order (PO):** Upon customer payment confirmation, Odoo automatically creates and approves a **Purchase Order (PO)** sent directly to the assigned supplier.
 3. **White-Label Fulfillment:** The supplier prints the shipping label generated by Odoo (featuring **Elitedom** branding exclusively) and ships the item directly to the buyer.
 4. **Account Settlement:** Odoo links the supplier's **Vendor Bill** with the customer's **Sales Invoice** to calculate net profit margins automatically.
## 4. Serial Tracking & RMA Warranty Workflow
*Protects both customer rights and store inventory against fraudulent returns.*
 1. **Intake Registration:** Scanned Serial Numbers are logged under stock.lot upon initial inventory receipt.
 2. **Warranty Activation:** Upon sale, the scanned Serial Number links to the customer invoice and sets the warranty start date.
 3. **Digital Claim Submission (RMA):**
   * Customer submits a return/warranty claim via **Typeform** (uploading photos/videos and Serial Number).
   * Data automatically syncs to create an **Odoo Helpdesk Ticket**.
 4. **Verification & Action:**
   * Support agents verify the Serial Number match and active warranty window.
   * **Approved:** Odoo creates an automated Return & Replacement order or refund.
   * **Rejected:** Agent notifies the customer with detailed verification notes.
## 5. Multi-Currency & B2B Pricing Workflows
| Process | Automation Logic |
|---|---|
| **USD Rate Fluctuation** | Update res_currency_rate -> System recalculates EGP retail prices (list_price_egp) based on targeted profit margins. |
| **B2B Corporate Pricing** | Assign customer account to B2B Pricelist -> System automatically applies volume discounts (e.g., 5% to 10% off for 10+ units) upon user login. |
## 6. Zero-Cost Maintenance & System Automation
To minimize human error and operational overhead without additional SaaS expenses, the infrastructure utilizes native background automated tasks:
 * **Odoo Automated Actions:** Triggers invoice creation, email generation, and status changes instantly based on database events.
 * **Odoo Cron Jobs:** Executes scheduled background tasks (e.g., daily price recalculations, temporary file cleanup, database maintenance).
 * **Systemd Python Scripts:** Lightweight Linux background services used for server health monitoring and hashing payment records to the Hedera network.
 * **Log Rotation:** Automatically rotates and clears old system logs to protect Oracle Cloud storage from reaching full capacity.
