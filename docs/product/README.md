# Product Documentation

Product intent, capabilities, requirements, user stories and traceability. Product documents define desired outcomes; executable code and acceptance evidence determine what is delivered.

## Maintenance

Documents in this area follow [`../governance/DOCUMENTATION_STANDARD.md`](../governance/DOCUMENTATION_STANDARD.md) where that relative path resolves from the top-level category. Each living document must state current status, source-of-truth paths, verification method, and change trigger.
