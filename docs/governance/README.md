# Documentation Governance

Rules that keep the documentation corpus accurate, reviewable, owned and distinguishable from historical or planned material.

## Maintenance

Documents in this area follow [`DOCUMENTATION_STANDARD.md`](DOCUMENTATION_STANDARD.md) where that relative path resolves from the top-level category. Each living document must state current status, source-of-truth paths, verification method, and change trigger.
